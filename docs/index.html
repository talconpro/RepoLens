What it does

把陌生仓库变成可阅读的学习地图

仓库速读

读取 README、目录结构、配置文件和关键源码抽样，帮助你快速建立项目全局视图。

AI 分析报告

使用你配置的 OpenAI 兼容接口生成结构化报告，支持中文和中英双语。

本地历史

分析结果保存在浏览器本地，可从历史页再次打开报告或回到 GitHub 仓库。

导出沉淀

报告支持 Markdown 和 HTML 下载，适合学习记录、团队分享和内容整理。

Install

安装和使用

  1. 从 GitHub Release 下载 `repolens-extension-v*.zip` 并解压。
  2. 打开 Chrome 的 `chrome://extensions`，启用开发者模式。
  3. 点击“加载已解压的扩展程序”，选择解压后的扩展目录。
  4. 打开 RepoLens 设置页，填写 API Base URL、API Key 和模型名。
  5. 进入 GitHub 公开仓库页面，点击插件图标并开始分析。

Privacy

API Key 和报告都留在你的浏览器里

RepoLens 不提供自建后端。插件直接读取公开 GitHub API，并直接调用你配置的 OpenAI 兼容接口。 API Key 与历史报告保存在 `chrome.storage.local`。
